## Rules

- Do not change the `<title>` or H1 of a target page unless Search Console shows
  the page is targeting the wrong query. An earlier Search Console export showed
  five title variants for both `/videography-dublin/` and `/photography-dublin/`
  between July and October.
- Blog posts answer the question and link once, in the body text, to the target
  page with a descriptive anchor (for example "business video production in
  Dublin", "commercial studio photography").
- A non-target page that ranks for a target keyword links to the target page; it
  does not add more copy for that keyword.
